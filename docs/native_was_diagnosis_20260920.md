# Native 上 attention / hetero 的 WAS 差异：本地诊断

> 历史诊断：本文记录修复前的 legacy 行为。现已实现 native `reference_v1` 的真实 WAS，
> 并发现/修正缺陷原子定位及空位图少一个真实原子的问题。用法与全量检查见
> [native_true_was.md](native_true_was.md)。本文件和原始报告保留作旧结果溯源；
> `audit_native_was` 脚本显式使用 legacy，不评估新版本。

## 结论和边界

目前不能把用户观察到的 MAE 差异归因于 random seed，也不能认定是原占位元素信息的收益。
**当前 native 实现中，未标注的 WAS 实际是重复当前元素特征。** 已验证的直接变化是输入
参数化、初始化和优化过程；attention 与 hetero 的不同读出方式是进一步需要验证的因素。

本次检查当前本地 ALIGNN 代码、native 数据以及新建模型的前向行为。
没有启动实验训练，也没有用户运行机器上四组模型的最新 checkpoint / 逐 seed MAE。
因此下述实测不构成四组模型的性能评估，也不证明远端训练一定使用相同代码版本。

复现：从 HERA 的父目录执行 `python -m HERA.scripts.audit_native_was`。
原始报告：`results/native_was_audit_20260920.json`。

## 1. WAS 是否真的包含过去的元素？

`data/datasets.py::load_data_native` 给 hetero、attention 的结构转换均传入
`skip_was=True`。`data/converters.py::AtomFeaturesExtractor` 对缺失 `was` 的站点
回退为 `current_z`，因此：

\[
x_i^{\mathrm{normal}}=E(Z_i),\qquad
x_i^{\mathrm{WAS}}=[E(Z_i),E(Z_i)].
\]

对空位 X，当前 Z=0，因此输入是 `[0,0]`，不会自动补入被删除元素的编码。

本地数据表包含 3,070 个构型、34 种材料、310 个去掉 POSCAR 序号后的缺陷系列。
按材料和缺陷类别分成 98 组，每组抽取首尾样本，共检查 **196 个结构、12,544 个图节点**：

- 原始结构和转换后结构均未发现 `was` 标注。
- 全部 WAS 向量的前后 92 维相同，前半与普通输入相同。
- attention 与 hetero 对应的站点、几何和初始特征一致。
- 每图只有一个实际缺陷节点。

样本是按类别抽取，不能用它替代远端输入与代码版本的核验。

## 2. 为什么没有新信息仍可能改变 MAE？

第一层是 Linear → normalization → SiLU。重复输入的线性部分满足：

\[
W_{\mathrm{WAS}}[x,x]+b=W_1x+W_2x+b=(W_1+W_2)x+b.
\]

把 WAS 模型的第一层折叠为 `W = W1 + W2`，其余权重完整复制，即可在重复输入条件下
构造相同函数的普通模型。对三个真实结构（空位、替位、间隙）实测未训练模型前向：

| 模型 | 普通参数量 | WAS 参数量 | 折叠后的最大输出差异 |
|---|---:|---:|---:|
| AttentionALIGNN | 310,215 | 316,103 | 5.22 × 10⁻⁸ |
| Shared-residual HeteroALIGNN | 679,193 | 690,969 | 1.04 × 10⁻⁷ |

这些是未缩放的前向数值误差，不是 eV/meV 测试 MAE。hetero 使用本轮 benchmark 的
`defect_energy_mean`、rank 8、AA/DD keep、r=0。两对模型内部的图连接和几何均未改变。

因此，这里不能简单解释为“参数增加，所以模型表达能力增加”。在重复输入这个约束下，
新输入权重存在冗余，但**训练路径会变化**：

1. 输入层由 92 维变为 184 维，随机数消耗及初始化分布随之改变。即使都设 seed=123，
   attention 有 131 个、hetero 有 202 个同形状 state tensor 的初始值不同；不只是输入层。
2. 对重复特征，`W1`、`W2` 的数据梯度相同。以 SGD 为例，若都用步长 η 更新，
   有效权重 `W1+W2` 的数据更新是 `-2ηG`，而单个 W 是 `-ηG`。
   当前代码使用 AdamW；两半自适应更新相加，同样不能视作与原模型相同的优化轨迹。
   这不是说整个网络的学习率都翻倍。
3. 后续学习率调度、验证集最优 epoch 和早停也可能随训练轨迹变化。

可复现的相同 seed，不等于不同输入维度模型逐层拥有相同初始权重。这属于正常的初始化
和优化差异，不能仅凭一个结果判定为 seed 实现错误。

## 3. 为什么 attention 可能比 hetero 更受益？（待验证的机制）

当前 AttentionALIGNN 在全体节点上做可学习的注意力加权读出，权重同时依赖节点表示、
缺陷类型和全图平均表示。普通原子的表示可以直接进入最终池化。

本轮 hetero 使用 `defect_energy_mean`：先对实际缺陷的最终 embedding 做预测，再取平均。
普通原子仍通过消息传递影响缺陷，但没有独立的全图读出通道。

因此，同样的输入参数化变化，可能对“全图加权汇总”和“把环境压入一个缺陷向量”产生
不同效果。native 包含多个材料和缺陷类型，这个差别值得做对照；**目前没有实验能证明
它就是 attention_was 增益更大的主因**。

另一个容易误判的点：本次样本均为单缺陷。只有一个缺陷时，`defect_mean` 与
`defect_energy_mean` 的前后运算顺序等价，不能靠交换 MLP 与缺陷平均的顺序解释差异。

## 4. Seed 和 native 划分还有什么问题？

`main.py::iter_train_val_test_splits` 的一个 seed 同时用于约 60/20/20 划分；同一个 seed
又被用于模型初始化。因此当前不同 seed 的误差波动混合了“测试集变了”和“初始化变了”。
同一 seed 下四种模式若使用相同有效样本列表，其划分应一致；需核对 checkpoint 保存的
train/val/test sources，而不是只看文件名。

对本地 3,070 行名单按当前划分规则统计：

| seed | 测试样本数 | 训练集中已有同一缺陷系列其他 POSCAR 的测试样本 |
|---|---:|---:|
| 123 | 614 | 598（97.39%） |
| 11 | 614 | 602（98.05%） |
| 1245 | 614 | 596（97.07%） |

这里“同一系列”按文件名去掉 `-POSCAR数字` 定义，不表示构型完全相同，也没有对坐标
相似度作判断。它说明当前评估主要是同系列内插，不能直接当成对未知缺陷/未知材料的外推。
这是四组共同的评估条件，单凭它也不能解释 WAS 的增益差异。

## 5. 最小的后续判别方案

1. **先核对已有结果，不重训。** 四组分别记录逐 seed test MAE、best-val、best epoch、
   数据划分、代码版本、batch size、LayerNorm/BatchNorm、旧 residual-normalization 开关、
   hetero pooling 和 AA/DD 配置。当前 native attention 默认 batch=16，而此前 relation
   benchmark 显式使用 batch=8；这是待核对的潜在训练设置差异，不是已确认的远端配置。
2. **做逐 seed 配对。** 分别计算 attention 和 hetero 的
   `Δ = MAE_WAS - MAE_normal`。看各 seed 的方向、均值和离散程度；一个 seed 的显著下降
   不能排除偶然波动，三个 seed 也不足以单独分解划分方差与初始化方差。
3. **若需要实验证明机制，分开固定划分与初始化。** 固定一个 split，做多个初始化；
   对比普通输入与重复输入，并让其他层权重一致、初始输入函数一致。
   再比较普通输入层调整步长的对照，判断参数化/优化是否足以解释收益。
   现有 CLI 的 `--seed` 会同时改变两者，不能直接用它当作这个解耦实验。
4. **真正 WAS 是另一个对照。** 在确认缺陷位置后，为 vacancy 提供被移除元素，
   substitution 提供原占位元素，interstitial 使用“原本无原子”的编码。
   其余普通原子的原占位元素保持自身。不能把当前 `[E(Z),E(Z)]` 的收益称作这个对照的收益。
5. 对跨缺陷泛化另做按缺陷系列分组划分；不要把它和当前随机构型划分的 MAE 混在一起。

本轮只增加审计脚本和报告，没有改变数据构图、WAS 定义、模型、训练协议或已有结果。
