# semi / imp2d 划分与标签复查

检查对象：`logs/alignn_physical_clean` 中 seed 123 的冻结过滤清单。
semi 保留 11,950 条；imp2d 保留 9,683 条。本次只审计，没有改动原数据、过滤决定或 split，也没有训练模型。

## 结论

**样本 ID 没有跨集合重复，但不同 ID 对应相同或近乎相同的原子结构，存在结构重复跨集合的问题。**
此前质量过滤保留了旧的按样本随机划分，未按结构等价组划分，因此物理过滤不等于消除了数据泄漏。

| 数据集 | 几何等价容差 | 等价样本对 | 涉及不同样本 | 跨任意两个集合的样本对 | train/test 样本对 |
|---|---|---:|---:|---:|---:|
| semi | 1e-6 Å | 0 | 0 | 0 | 0 |
| semi | 1e-3 Å | 160 | 298 | 87 | 32 |
| imp2d | 1e-6 Å | 73 | 146 | 43 | 26 |
| imp2d | 1e-3 Å | 95 | 190 | 50 | 29 |

不同容差的行互相包含，不可相加。样本可能出现在多个配对中，样本对数也不能当作样本数。
semi 的 160 对对应 143 个连通组；imp2d 的 95 对各是一个二元组。
imp2d 另有 36 对连 CIF 文件字节都完全相同，其中 22 对跨集合，13 对跨 train/test。

明确的例子：`MoS2_Be_int4` 位于 test，`MoS2_Be_int3` 位于 train；
两个 CIF 字节完全相同，形成能均为 4.087730675 eV。

native 另做了 strict44 清单的 ID 与文件字节哈希检查：3,026 条保留记录没有重复 ID、没有相同文件哈希。
本次未对 native 做完整的对称等价/近似几何检查，因此不能据此宣布 native 已消除所有结构重复。

## 同结构不同能量

### semi

本轮 160 对近似等价结构中，最大形成能差为 **0.00060193 eV（0.60193 meV）**，
没有超过 0.05 eV 的新增冲突。这些差异很小，主要需要处理跨集合的相关样本。
它们不同于此前已经隔离的 77 对/154 条完全相同 CIF、形成能相差 0.08477～1.79113 eV 的记录。

### imp2d

有两对在 0.001 Å 容差下近似等价，形成能相差超过 0.05 eV：

| 样本对 | 所在集合 | 形成能差 | 数据库 spin 字段 | 处理结论 |
|---|---|---:|---|---|
| NbSe2_Fe_int4 / NbSe2_Fe_int3 | val / test | 0.20602087 eV | 1 / 1 | 优先复查原始 DFT 记录 |
| MoS2_Zn_int4 / MoS2_Zn_int3 | val / val | 0.05915698 eV | 0 / 2 | 可能涉及不同磁性状态，不能直接断言错标签 |

Fe 对的 hostenergy 和化学势相同，差异来自 en2。
`int4` 的 conv2 为 0.0102573 eV，`int3` 为 −0.0000650527 eV；均通过当前 0.05 eV 筛查阈值，
但这不足以证明两次计算达到同一电子状态或完全相同的数值精度。
没有原始迭代日志，无法确定差异的具体原因。

另有 **CIF 字节完全相同** 的 `NbSe2_H_int4 / NbSe2_H_int3`，分别在 val/train，
形成能差 0.03752713 eV，spin 为 0/2。
因此“36 对完全相同 CIF 的能量全部相同”不准确；部分标签有差异，最大为 0.03752713 eV。
这些差异没有超过此前 0.05 eV 的一致性容差，但对不输入磁性状态的模型仍可能形成目标歧义。

以上两对较大差异仅标记复查，没有自动删掉或取最低能量。近似结构相同不证明完整 DFT 状态相同。

## 方法与限制

- 在同一宿主、杂质元素和完整原子组成/原子数内比较，使用 pymatgen StructureMatcher。
- 允许周期平移、原子重排和晶体对称等价；不缩放晶胞、不展开超胞、不将结构化成原胞。
- 0.001 Å 为近似几何审计容差；另报告 1e-6 Å 的更严格结果。
- 比较前按晶胞体积和唯一稀有元素到各元素的周期距离作候选筛选。
- 实际 CIF 哈希核对冻结清单。imp2d 使用与清单 SHA256 一致的原始 db 坐标，
  此 db 的结构与实际训练 CIF 已在物理预处理中逐条核对。
- 测试了平移、原子重排、对称操作不改变匹配，明显移动原子应拒绝，小位移能区分两档容差。
- 这些是当前严格候选筛选下发现的重复，不排除较大几何差异、不同超胞表示或同一弛豫轨迹带来的更广泛相关性。
- 同材料但不同构型跨集合是否允许，取决于 benchmark 目标，不能仅凭材料名相同判作划分错误。

## 应如何修正

正式比较模型时，应把等价/近似等价结构的连通组作为划分单位，同组只能进入 train、val、test 中一个集合。
标签冲突和磁性状态差异需要单独处理；不能靠随机 seed 消除，也不能仅删除预测误差大的测试样本。
重新按组划分会改变基准测试，应在新的实验版本中让所有模型使用同一组 split，重新训练与评估。

当前训练命令仍保留旧 split；本次没有悄悄重排已冻结的清单。
直接从 db 读取结构可以省略 CIF，但不会自动修复这个划分问题。

## 输出与复现

- `results/impurity_split_audit/summary.json`：两组完整统计及清单身份。
- `semi_cross_split_pairs.csv` / `imp2d_cross_split_pairs.csv`：跨集合的具体 ID、标签和匹配精度。
- `semi_equivalent_pairs.csv` / `imp2d_equivalent_pairs.csv`：所有发现的等价对。
- `imp2d_label_conflicts.csv`：两对超过 0.05 eV 的待复查记录。
- `imp2d_conflict_metadata_review.json`：上述能量分项、收敛指标和 spin。

在 HERA 的父目录运行，仅审计、不训练：

```bash
python -m HERA.scripts.audit_impurity_splits --dataset semi imp2d
```

另：缺少数据库的机器现在可在 `--imp2d-quality-filter physical` 首次读取时自动下载官方 db，
验证固定版本后写入 `dataset/imp2d/imp2d.db`。网络获取和原始字节 SHA256 已实测，27 项相关测试通过。
